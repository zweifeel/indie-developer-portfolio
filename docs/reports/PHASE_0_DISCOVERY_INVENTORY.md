## 11. METADATA SCHEMA ARCHITECTURE

The progress metadata schema (`src/types/portfolioProgress.ts` & `PORTFOLIO_METADATA_SCHEMA.md`) is built on Schema Version 1:
- **Strict Status Separation:**
  - `implementationStatus`: `planned` | `in_progress` | `completed` | `on_hold` | `cancelled`
  - `publicationStatus`: `draft` | `public` | `hidden`
- **Mandatory Defaults:**
  - Every newly created milestone or feature defaults to `publicationStatus: 'draft'`.
  - Reaching `completed` implementation status **never** automatically marks an item `public`.
  - Setting `publicationStatus: 'hidden'` instantly purges the item from all public API outputs.

## 12. PROHIBITED KEY & FORBIDDEN PROPERTY FIREWALL

The validator enforces a blacklist of forbidden properties (`PROHIBITED_METADATA_KEYS`):
- `commitHash`, `sha`, `gitRef`, `branch`
- `authorEmail`, `committer`, `contributor`
- `secret`, `token`, `password`, `apiKey`, `auth`
- `internalUrl`, `privateIp`, `databaseUrl`, `credentials`

Any payload containing these keys is rejected with a fail-closed validation error.
